## 🍱 Food Bridge Connect

<details>
<summary><strong>Food Bridge Connect — AI-Powered Food Waste Management Platform</strong></summary>

<br/>

**Food Bridge Connect** is a mobile application designed around the problem of **surplus food management and redistribution**.

The project explores how technology can connect surplus food sources with organizations or individuals who can make meaningful use of that food, while incorporating intelligent features for prediction, matching, freshness estimation, and route optimization.

### Project Architecture

| Category | Details |
|---|---|
| **Stack** | Kotlin, Android Studio, Firebase, AI/ML concepts |
| **Platform** | Android |
| **Scale** | Multi-user food redistribution ecosystem |
| **AI Layer** | Surplus food prediction, freshness estimation, intelligent matching |
| **Optimization** | Route optimization and location-based matching |
| **Security** | Authentication, structured backend data management, controlled user interactions |
| **Core Features** | Food listing, matching, geolocation, freshness estimation, ratings |
| **Domain** | Food Waste Management / Social Impact / AI |
| **Repository** | [FOOD-BRIDGE-CONNECT](https://github.com/yashikasingh1307/FOOD-BRIDGE-CONNECT) |

### Engineering Scope

- Designed an Android-based workflow for connecting surplus food with potential recipients.
- Explored **AI-assisted surplus food prediction**.
- Incorporated **freshness estimation** as part of food usability evaluation.
- Implemented the concept of intelligent food-to-recipient matching.
- Considered **geolocation and route optimization** for efficient redistribution.
- Added a rating-based mechanism to support trust within the platform.
- Incorporated food-safety considerations aligned with relevant **FSSAI guidelines**.
- Developed as a collaborative engineering project using Android Studio and Kotlin.
- Participated in the **Dilli AI Grind hackathon**, where the project progressed to the district level.

### Skills Demonstrated

`Kotlin` `Android Development` `Firebase` `AI/ML` `Geolocation` `Product Engineering` `Team Collaboration`

🔗 **Repository:** https://github.com/yashikasingh1307/FOOD-BRIDGE-CONNECT
